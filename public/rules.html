墙规 / 发帖须知

发帖前请花一分钟读完。校园墙是大家的公共空间，友善和真实是底线。

一、绝对禁止的内容

人身攻击 / 辱骂对他人进行侮辱、嘲讽、恶意贬低。
挂人 / 曝光隐私未经同意公开他人姓名、照片、学号、手机号、社交账号等。
色情 / 低俗任何色情、擦边、性骚扰相关内容。
诈骗 / 违法虚假交易、刷单、贷款、代考、代写等违法违规信息。
校外广告校外商家的硬广、拉群、引流。校园社团活动除外。
考试作弊信息出售答案、替考、作弊器材等。
引战 / 挑事地域、性别、院系对立，恶意带节奏。
虚假信息编造突发事件、谣言、冒充他人或官方发布。

违规处理：内容会被删除，视情节对发布 IP 进行封禁（禁止发帖 / 评论），严重者永久拉黑。

二、发帖规范

  • 选择正确的分类，方便同学快速找到信息；
  • 正文写清楚时间、地点、物品等关键信息（尤其是失物招领）；
  • 图片请打码处理他人的面部、证件、学号、联系方式；
  • 一条帖子只讲一件事，不要重复刷屏；同一内容多次提交会被忽略；
  • 联系方式为自愿填写，填写即表示你同意公开展示。

三、审核与展示

所有新帖先进入待审核队列，管理员审核通过后才会在首页展示。审核通常在收到后尽快完成，请耐心等待，不要重复提交。被驳回的帖子会记录原因，你可以通过 申诉页面 提交复核申请。

四、闲置交易风险提示

校园墙仅提供信息发布，不参与任何交易、不承担交易风险。请优先选择校内当面交易、当面验货；不要提前转账，不要点击陌生链接，谨防诈骗。

五、隐私与责任

  • 请勿发布他人照片、学号、手机号等个人信息；如涉及隐私，管理员会直接删除；
  • 每条帖子内容仅代表发布者个人观点，与校园墙运营方无关；
  • 因发布者自身原因造成的纠纷与损失，由发布者自行承担。

六、举报与申诉

发现违规内容，可点击帖子或评论上的「举报」按钮，选择理由并提交。被误删、误判的用户可在 申诉页面 留下帖子编号与说明，管理员会人工复核。

🤝 校园墙希望成为让每个人都能安心说话的地方。谢谢你维护它。
