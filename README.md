# WallTHUFake

WallTHU 的模拟/演示版本。

## 简介

本项目用于复现和演示 WallTHU 的核心功能，便于在本地环境进行开发、测试与展示。

> 项目尚处于初始阶段，内容会持续补充。

## 快速开始

```bash
git clone https://github.com/GaryHU233/WallTHUFake.git
cd WallTHUFake
```

运行方式待项目代码加入后补充。
